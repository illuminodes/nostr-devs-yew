# NostrDevs San Salvador

## Español

Este repositorio contiene los temas discutidos en los pasados meetups, así como 
servir como medio para sugerir temas para futuros meetups.

### Contribuir 

Siéntete libre de sugerir temas para futuros meetups. Puedes abrir una `issue` en el repositorio con su sugerencia, o
directamente crear un `pull request` agregando tu sugerencia al archivo `src/content.rs`.

## English

This repository contains the topics discussed at past meetups, as well as serve 
as sharing board to suggest topics for future meetups.

### Contributing

Feel free to suggest topics for future meetups. You can open an issue on the repository with your suggestion, or 
directly create a pull request by adding your suggestion to the `src/content.rs` file.
